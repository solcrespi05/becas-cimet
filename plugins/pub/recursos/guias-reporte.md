# Guías de reporte (EQUATOR Network)

> Elegí la guía por diseño. La lista oficial y las versiones vigentes están en https://www.equator-network.org — confirmá ahí la versión antes de aplicarla y citá la fuente en el informe.

| Diseño | Guía | Extensiones frecuentes |
|---|---|---|
| Ensayo clínico aleatorizado | CONSORT | CONSORT-AI, extensiones para cluster, no inferioridad, pilotos |
| Protocolo de ensayo | SPIRIT | SPIRIT-AI |
| Cohorte, casos y controles, transversal | STROBE | RECORD (datos de rutina/registros), STROBE-ME (epidemiología molecular) |
| Precisión diagnóstica | STARD | STARD-AI (verificar estado) |
| Modelo de predicción o pronóstico (incluido ML) | TRIPOD+AI | PROBAST para riesgo de sesgo |
| Revisión sistemática / metaanálisis | PRISMA 2020 | PRISMA-S (búsqueda), PRISMA-ScR (scoping) |
| Reporte de caso | CARE | |
| Evaluación económica | CHEERS 2022 | |
| Investigación cualitativa | COREQ, SRQR | |
| Mejora de calidad | SQUIRE 2.0 | |
| Estudios en animales | ARRIVE 2.0 | |
| Estudios genéticos de asociación | STREGA | |
| Modelado de enfermedades infecciosas / epidemiológico | (verificar guías específicas vigentes en EQUATOR) | |
| Abstracts | CONSORT for Abstracts, PRISMA for Abstracts | |

## Cómo aplicarla
1. Confirmá el diseño en `notas.md` o en métodos; si es ambiguo, preguntá.
2. Recorré cada ítem de la guía: ✅ reportado (cita del texto), ⚠️ parcial, ❌ ausente, N/A con motivo.
3. Muchas revistas piden la checklist completa con números de página: dejala lista en `revision/guia_<nombre>.md`.
